# 字体来源与许可说明

## ChironSungHK-M-subset.woff2
- 字体: 昭源宋體 Chiron Sung HK (Medium)
- 来源: https://github.com/chiron-fonts/chiron-sung-hk (v1.024)
- 许可: SIL Open Font License 1.1
- 用途: 站名/界面宋体 (风格对齐港铁站牌字体「铁宋/香港铁路宋」, 后者为港铁公司专有字体;
  如已本地安装正版 MTR Sung, CSS 字体链会自动优先使用)
- 说明: 已按项目内实际用字子集化 (fonttools), 新增站名/文案后需重新子集化

## DottedSongtiSquare-subset.woff2
- 字体: Dotted Songti Square 点阵宋体·方点 (v0.1)
- 来源: https://github.com/wixette/dotted-chinese-fonts
- 许可: GPL-2.0 (衍生自文泉驿点阵宋体)
- 用途: 数字/时间显示的点状像素字体
- 说明: 仅保留 ASCII 与 ℃ 等符号
